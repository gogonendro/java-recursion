# java-recursion

Java programs demonstrating **recursive problem-solving and fundamental recursion concepts** at the Class XII level

> **Note:** This repository is created solely for **learning and educational purposes**, with the aim of understanding recursion and applying recursive techniques to different programming problems.

## What this repository contains

This repository contains **10 Java programs** that demonstrate recursion through mathematical, number-based, and array-based problems

1. **Factorial** — calculates the factorial of a number using recursion.
2. **Sum** — finds the sum of the first `n` natural numbers using recursion.
3. **Power** — calculates the power of a number using recursive multiplication.
4. **SumDigit** — finds the sum of the digits of a number recursively.
5. **GCD** — finds the Greatest Common Divisor of two numbers using the Euclidean algorithm recursively.
6. **Fibonacci** — finds the `n`th Fibonacci term using recursive calls.
7. **Reverse** — reverses the digits of a number using recursion.
8. **DigitCount** — counts the number of digits in a number recursively.
9. **ArraySum** — finds the sum of all elements in an array using recursion.
10. **MaxEle** — finds the largest element in an array using recursion.

## Concepts Covered

- Recursion and recursive calls
- Base cases and recursive cases
- Recursive mathematical calculations
- Digit manipulation using recursion
- Euclidean algorithm
- Fibonacci sequence
- Number reversal
- Recursive array traversal
- Finding array maximum recursively
- Problem solving using recursion in Java
